A single deadpan one-line roast of a smart fridge, generated by a tiny deterministic program: a firmware update locks the ice maker behind new terms, and the punchline is the price paid for a cold drink.

## Run it

```sh
python3 main.py
```

It writes one line of comedy (116 characters) to `/output/entry.txt`. Standard library only, no network, no input files, and the same bytes on every run from any working directory.
